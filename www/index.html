📦 APK / AAB Build

⚠️ वास्तविक APK/AAB बनाने के लिए Android SDK/Gradle वाला ऑनलाइन Build Server, signing key और सुरक्षित server connection जरूरी है। इस फाइल में कोई Build Server URL या credentials सेट नहीं हैं।
Build से पहले जाँच चलाकर Package ID, Version और HTML की तैयारी जाँचें।
Android Project ZIP में Capacitor Android dependency, README और build scripts मिलेंगे। अंतिम APK/AAB बनाने के लिए Android Studio/SDK और Gradle चलाना होगा।
Android Project ZIP आपके HTML को Capacitor के www/index.html में रखेगी और package.json, capacitor.config.json तथा build guide जोड़ेगी। इससे Android Studio में आगे APK/AAB बनाना संभव होगा।

📘 CSY Converter कैसे इस्तेमाल करें

यह टूल HTML प्रोजेक्ट बनाने, देखने, सेव करने और ZIP/HTML में एक्सपोर्ट करने के लिए है।

1
प्रोजेक्ट बनाएं

प्रोजेक्ट और ऐप का नाम लिखें, भाषा, थीम और Online/Offline मोड चुनें।

2
HTML या ZIP अपलोड करें

मौजूदा HTML फाइल चुनें या ZIP पैकेज इम्पोर्ट करें। ZIP फीचर के लिए इंटरनेट और JSZip लाइब्रेरी जरूरी है।

3
कोड एडिट और Preview करें

Editor में HTML बदलें। Live Preview से देखें और Error Checker से JavaScript syntax की सामान्य जाँच करें।

4
APP READY और डाउनलोड

HTML डाउनलोड करें या ZIP पैकेज बनाएं। JSON बैकअप से प्रोजेक्ट वापस इम्पोर्ट किया जा सकता है।

5
Build से पहले जाँच

Build से पहले जाँचें बटन Package ID, Version, ऐप का नाम, HTML और JavaScript की सामान्य तैयारी जाँचता है।

6
पूरा Android Build प्रोसेस (GitHub Actions)

Android Project ZIP को GitHub Repository में डालें, Actions टैब में CSY Android Build चुनें और Run workflow दबाएँ। Artifacts में Debug APK और Release APK/AAB मिलेंगे। Release files signed होंगी यदि चारों signing Secrets configure किए गए हों; अन्यथा unsigned रहेंगी। Build Report में SHA-256 checksums भी मिलेंगे।

\n
7
APK/AAB बनाना

अंतिम APK/AAB के लिए Android build service चाहिए। Android SDK/Gradle, ऐप signing और server API के बिना ब्राउज़र अकेले वास्तविक APK नहीं बना सकता।

आपका कोड इस HTML टूल में स्थानीय रूप से रहता है। Preview sandbox में चलता है। ऑनलाइन URL से दूसरी वेबसाइट का कोड सीधे पढ़ना browser CORS सुरक्षा के कारण सीमित हो सकता है। यह HTML टूल Android Starter Project और Cloud Build workflow तैयार करता है। वास्तविक APK/AAB GitHub Actions या Android Studio Build Environment में बनते हैं; यह ब्राउज़र अकेले APK compile नहीं करता।
